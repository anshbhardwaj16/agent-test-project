# Contributing to agent-test-project

This document describes **how** to make changes here. For **what**
this repo is and what it owns, see [README.md](README.md).

## Branch naming

Every feature branch in the workspace — local-only or cross-repo —
uses the single unified pattern:

    feature/EDAA-{NUM}-{slug}-{YYYYMMDD}

The same branch name is created in every touched repo, so a one-line
grep across the workspace finds the whole change. The framework
derives the name automatically — you should not need to construct
it by hand.

## Code conventions

- Tool definitions live in the `TOOLS` list at the top of `agent.py` — add new tools there, then add a matching branch in `handle_tool_call()`.
- Tool handlers must return a JSON string (use `json.dumps`). Never return raw text.
- Keep `eval` calls sandboxed: pass `{"__builtins__": {}}` as the globals dict.
- Test files mirror the module under test: `test_agent.py` covers `agent.py`.

## Testing

```bash
pytest test_agent.py
```

Story-level tests are generated by `/ci:gen-tests` mapped 1:1
to acceptance criteria.

## PR process

1. **Plan** — `/jira:pickup-story EDAA-{NUM}` — auto-classifies which
   repo(s) to touch; if the story spans multiple repos a coordinated
   branch is created in each
2. **Implement + test** — `/ci:gen-tests EDAA-{NUM}` — generates
   AC-mapped tests, runs the suite, auto-fixes failures
3. **Review** — `/git:submit-pr EDAA-{NUM}` — runs the gate chain,
   opens the PR with cross-links to sibling repo PRs
4. **Test in QA** — `/ci:qa-run EDAA-{NUM}` — runs against QA env
5. **Close** — `/jira:close EDAA-{NUM}` — transitions to Done

Failure recovery: `/jira:resume EDAA-{NUM}`

## Cross-repo coordination

No cross-repo coordination rules declared. Add them to the
`cross_repo_coordination:` block in this file's frontmatter as
dependencies on other repos emerge.

## Pre-commit gate

This repo has a pre-commit hook that validates README + CONTRIBUTING
frontmatter on every commit that touches either file. To run it manually:

```bash
python ../omnispark/scripts/validate_repo_docs.py --repo agent-test-project
```

To bypass once (NOT recommended): `OMNISPARK_SKIP_HOOK=1 git commit`.
